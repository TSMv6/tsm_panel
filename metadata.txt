description=A QGIS plugin to interface with the Turnpike State Model (TSM) version 6 - configure, run and summarize the full model chain from one panel.
about=TSM version 6 (TSMv6) is Florida's Turnpike statewide, agent-based
    travel model. This plugin is the model's user interface: a dockable QGIS
    panel that configures a scenario (General Configuration, Scenario Specs,
    saved/loaded as a per-scenario settings JSON), runs each model step with a
    checkbox ("Check Full Run" chains steps 1-10), live-logs every run, and
    loads/summarizes the outputs as QGIS layers. All model engines are compiled
    C++ executables bundled under the plugin's Apps/ folder (with their own GDAL
    and VC runtime DLLs) - users install nothing beyond QGIS and this plugin.
    .
    Network models - GeoMaster (HERE/Navteq-based) network preparation:
    netPrep.exe (link consolidation: ~4M GeoMaster links filtered and merged to
    the ~600K-link TSM routable network + GMNS export) and PathSkim.exe
    (Skimmy: multithreaded path-based congested/free-flow skims to OMX).
    .
    Demand models - synthetic population and person/agent travel demand:
    popsim-run.exe + popsimprep.exe (PopSyn: IPF-based synthetic households,
    persons and group quarters), sdt-run.exe (short-distance resident and
    visitor tours), ldt-run.exe + ldtprep.exe (long-distance resident and
    visitor tours incl. air access/egress), and agentPlans.exe (assembles all
    markets - SDT/LDT/trucks/externals - into the hourly agent trip list and
    trip tables, with MSR disaggregation via msr.exe).
    .
    Routing models - two interchangeable assignment engines: ELToD.exe
    (TRANSIMS-based quasi-dynamic toll-choice assignment) and afdta.exe
    (HyDRA / AgentFlow-DTA: agent-based dynamic traffic assignment with
    point-queue, LTM and node-conserving nodeDNL loaders, meso/micro corridors,
    express-lane toll choice). Support utilities include se_aggregate.exe,
    gpkgcsv.exe, summarize.exe (loaded-network + validation summaries),
    subarea.exe, odme.exe and SkimConverter.exe.
    .
    Runs on QGIS 3.x (Qt5) and QGIS 4.x (Qt6) from a single code base via the
    qgis.PyQt compatibility layer.
