description=QGIS interface to Florida's Turnpike Enterprise (FTE's) State Model - TSM v6. Configure, run and summarize the full model chain from one panel.
about=TSMv6 is Florida's Turnpike Enterprise (FTE's) State Model (TSM): a
    statewide, agent-based travel model (AgBM = ABM + DTA); this plugin is its
    user interface. All engines are bundled C++ exes under Apps/ (with their
    own GDAL + VC runtime DLLs) - nothing to install beyond QGIS.
    .
    - Panel: per-scenario settings (JSON), step checkboxes, "Check Full Run"
    chains steps 1-10, live run logs (closing the log window cancels the run).
    - Network models: netPrep.exe (link consolidation + GMNS export),
    PathSkim.exe (Skimmy path-based skims to OMX).
    - Demand models: popsim-run.exe (PopSyn), sdt-run.exe, ldt-run.exe,
    agentPlans.exe (agent trip lists / trip tables, MSR).
    - Routing models: ELToD.exe (quasi-DTA toll choice) or afdta.exe
    (HyDRA agent-based DTA with nodeDNL loaders).
    - Analyst: summarize.exe loaded-network summaries + validation workbook.
    - Single code base for QGIS 3 (Qt5) and QGIS 4 (Qt6).
changelog=
    From TSMv5 to TSMv6: TSMv5 is a disaggregate TOUR-BASED demand model
    (activity-based model family, ABM) with static assignment. TSMv6 is an
    AGENT-BASED model (AgBM = ABM + DTA): the same disaggregate travelers
    become individual agents whose trips are listed by agentPlans and routed
    and loaded by dynamic traffic assignment (HyDRA/AgentFlow, or ELToD for
    quasi-DTA toll choice), run end to end from this panel. Base network
    updated to Navteq/HERE 2024 Q4 (GeoMaster); all models re-engineered onto
    a unified C++ codebase (R, Java, Pascal, and Python/Anaconda2 runtime
    engines replaced by the bundled exes).
    .
