# Skimmy GUI Widget User Guide

## Introduction
The Skimmy widget facilitates the generation of network skim matrices based on link and node datasets in the Turnpike State Model (TSM). Users can define network attributes and produce output skims in OMX or CSV formats.

---

## GUI Overview

### Input Configuration

#### 1. **Link Layer**
- **Description:** Specifies the polyline network layer used for skimming.
- **Interaction:** Select the appropriate line layer from the dropdown.

#### 2. **Node Layer**
- **Description:** Specifies the point layer representing network nodes.
- **Interaction:** Select the appropriate node layer from the dropdown.

---

### Coefficient Parameters

#### 1. **Distance Coefficient**
- **Description:** Weight applied to distance for skim calculation.
- **Interaction:** Enter a numeric value directly into the provided field.

#### 2. **Time Coefficient**
- **Description:** Weight applied to time for skim calculation.
- **Interaction:** Enter a numeric value directly into the provided field.

#### 3. **Cost Coefficient**
- **Description:** Weight applied to cost for skim calculation.
- **Interaction:** Enter a numeric value directly into the provided field.

---

### Output Configuration

#### 1. **Output Skim**
- **Description:** Destination file for the generated skim matrix.
- **Interaction:** Click the **Browse** button to specify a file path and name.

#### 2. **Output Format**
- **Description:** Choose the file format for the output skim (OMX or CSV).
- **Interaction:** Select the preferred format from the dropdown menu.

---

## Execution and Saving

### Run Skimmy
- Click **Run** to initiate skim generation based on specified configurations.

### Save or Cancel Configuration
- Click **Save** to retain settings for future runs.
- Click **Cancel** to discard unsaved changes and exit the widget.
