# Project Settings GUI Widget User Guide

## Introduction
The Project Settings widget manages scenario configurations for running the Turnpike State Model (TSM). It defines the scenario details, geographic coverage, input layers, and specific model steps to execute.

---

## GUI Overview

### Scenario Configuration

#### 1. **Scenario Name**
- **Description:** Defines a unique name for the current scenario.
- **Interaction:** Enter a descriptive scenario name in the provided text field.

#### 2. **Select Year**
- **Description:** Chooses the year associated with the scenario.
- **Interaction:** Select the scenario year from the dropdown menu.

#### 3. **Scenario Description**
- **Description:** Provides additional context or notes about the scenario.
- **Interaction:** Enter detailed notes in the text area provided.

---

### Geographic Coverage

- **Description:** Determines the geographic scope of the scenario.
- **Interaction:**
  - Select **Statewide** for broader coverage.
  - Select **Subarea** for focused geographic analyses.

---

### Input Layers

#### 1. **Network Link File**
- **Description:** Specifies the network line (link) layer for analysis.
- **Interaction:** Select the appropriate layer from the dropdown menu.

#### 2. **Network Node File**
- **Description:** Identifies the network node (point) layer.
- **Interaction:** Choose the correct layer from the provided dropdown menu.

#### 3. **SE Data Polygon File**
- **Description:** Selects the socio-economic (SE) data polygon layer for scenario processing.
- **Interaction:** Use the dropdown menu to select the relevant layer.

---

### Output Configuration

#### Output Directory
- **Description:** Sets the directory for storing scenario outputs.
- **Interaction:** Enter the directory manually or click **Browse** to select the destination folder.

---

### Black Box Steps
- **Description:** Selects specific model steps for scenario execution.
- **Available Options:**
  - PopSyn
  - LDT Resident
  - TSM Assignment
  - SDT Resident
  - LDT Visitor
  - SDT Visitor
  - TripList2Table
- **Interaction:** Check the boxes for desired steps to include in the scenario run.

---

## Saving or Cancelling Changes

### Apply and Save Changes
- Click **OK** to confirm and save your scenario configurations.

### Cancel Changes
- Click **Cancel** to discard changes and exit the widget without saving.
