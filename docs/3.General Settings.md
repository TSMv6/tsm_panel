# General Configuration GUI Widget User Guide

## Introduction
The General Configuration widget manages key dependencies and paths for running the Turnpike State Model (TSM). It is essential for ensuring the correct execution of simulation tasks and scripts.

---

## GUI Overview

### Configuration Components

#### 1. **JAVA Path**
- **Description:** Specifies the directory of the installed Java Development Kit (JDK). The JDK is necessary for executing Java-based applications within the TSM.
- **Interaction:**
  - Enter the path manually or click **Browse** to select the JDK directory.

#### 2. **RScript Path**
- **Description:** Defines the path to the Rscript executable, required for running R scripts that handle data processing within TSM.
- **Interaction:**
  - Enter the path manually or click **Browse** to select the Rscript executable.

#### 3. **TSM Location**
- **Description:** Points to the root directory of the Turnpike State Model. This location is used by various scripts and components of TSM.
- **Interaction:**
  - Enter the path manually or click **Browse** to select the TSM directory.

#### 4. **Number of Processors to Use**
- **Description:** Sets the number of processor cores allocated for simulation tasks. Optimizing this setting improves simulation performance.
- **Interaction:**
  - Enter the number of processors directly into the provided field.

---

## Saving or Cancelling Changes

### Apply and Save Changes
- Click **OK** to confirm and save your configurations.

### Cancel Changes
- Click **Cancel** to discard any changes and close the widget without saving.
