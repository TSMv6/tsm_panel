# Long-Distance Travel (LDT) Resident GUI Widget User Guide

## Introduction
The LDT Resident widget manages the modeling of long-distance travel specifically for Florida residents within the Turnpike State Model (TSM). This configuration utilizes Florida-specific data inputs to forecast travel behavior.

---

## GUI Overview

### Input Configuration

- **Input Directory:** Directory containing necessary input files.
  - Interaction: Click **Browse** to select the directory.

- **Road LOS (Skim):** Road level-of-service skim file.
  - Interaction: Click **Browse** to select the skim file.

- **Rail LOS (Skim):** Rail level-of-service skim file.
  - Interaction: Click **Browse** to select the skim file.

- **Air LOS (Skim):** Air travel level-of-service skim file.
  - Interaction: Click **Browse** to select the skim file.

- **Land-use (FL):** Florida-specific land-use data file.
  - Interaction: Click **Browse** to choose the file.

- **Synthetic HH (FL):** Florida synthetic household data file.
  - Interaction: Click **Browse** to choose the file.

- **Number of Households (FL):**
  - Interaction: Enter manually or check **Auto compute** to automatically calculate from synthetic HH data.

---

### Output Configuration
- **Output Directory:** Destination folder for model results.
  - Interaction: Click **Browse** to select or enter manually.

---

## Execution and Saving
- Click **Run** to execute the LDT Resident model.
- Use **Save** to store current settings or **Cancel** to discard changes.

---

## Additional Notes
- Ensure all skim and land-use data files are accurately selected and compatible.
- Regularly update synthetic household data to reflect current demographics.
