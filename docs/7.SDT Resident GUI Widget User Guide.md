# SDT Resident GUI Widget User Guide

## Introduction
The SDT Resident widget manages the Short Distance Travel (SDT) modeling for residents within the Turnpike State Model (TSM). It utilizes land-use data, synthetic household/population data, and skim matrices to evaluate travel patterns based on selected telework scenarios.

---

## GUI Overview

### Data Input Configuration

#### 1. **Land-use Layer**
- **Description:** Selects the polygon land-use layer at the regional planning level, aggregated internally to TSM zones.
- **Interaction:** Choose the appropriate polygon layer from the dropdown menu.

#### 2. **Synthetic Household File**
- **Description:** Specifies the synthetic household dataset generated from PopulationSIM.
- **Interaction:** Click **Browse** to select the file.

#### 3. **Synthetic Person File**
- **Description:** Defines the synthetic population dataset produced from PopulationSIM.
- **Interaction:** Click **Browse** to choose the file.

#### 4. **Skim File**
- **Description:** Provides the skim matrix (distance table) essential for travel modeling.
- **Interaction:** Click **Browse** to specify the skim file.

---

### Telework Scenario

- **Description:** Adjusts the telework share percentage, influencing travel demand.
- **Interaction:** Select the desired telework percentage (7%, 10%, 15%, 20%, or 25%) from the dropdown menu.

---

### Output Directory

- **Description:** Directory where model outputs will be stored.
- **Interaction:** Enter the directory path manually or click **Browse** to select.

---

## Execution and Saving

### Run SDT Resident
- Click **Run SDT** to execute the model based on configured inputs and telework scenario.

### Save or Cancel Configuration
- Click **OK** to save settings for future runs.
- Click **Cancel** to discard unsaved changes and exit the widget.
