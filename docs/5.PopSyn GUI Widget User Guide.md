# PopSyn GUI Widget User Guide

## Introduction
The PopSyn widget is part of the ActivitySIM framework used in the Turnpike State Model (TSM). This widget allows users to generate synthetic population data from land-use layers and manage incremental updates efficiently.

---

## GUI Overview

The GUI consists of two main sections:

### Standard Run Configuration

#### 1. **Land-use Layer**
- **Description:** Select a polygon land-use layer from QGIS layers.
- **Interaction:** Use the dropdown menu to select the desired polygon layer.

#### 2. **Output File: Households (HH)**
- **Description:** Specify the output file for synthesized household data.
- **Interaction:** Click **Browse** to select or specify a destination file.

#### 3. **Output File: Persons (PER)**
- **Description:** Specify the output file for synthesized population data.
- **Interaction:** Click **Browse** to select or specify a destination file.

#### 4. **GQ Included in POP**
- **Description:** Indicates if Group Quarters (GQ) are included within the total population.
- **Interaction:** Check to enable automatic internal handling; uncheck to exclude GQ.

---

### Incremental Run Configuration

#### 1. **Run Incremental**
- **Description:** Enables incremental synthesis mode, updating based on differences between two land-use datasets.
- **Interaction:** Check to enable incremental configuration; this activates additional reference file settings.

#### Incremental Configuration (Active if checked):

- **Reference File: LU**
  - Select the reference land-use polygon layer from the dropdown.

- **Reference File: HH**
  - Click **Browse** to select the reference household data file.

- **Reference File: PER**
  - Click **Browse** to select the reference population data file.

---

## Running PopSyn

### Steps to Execute
1. **Set all required configurations**:
   - Select land-use layers.
   - Specify file paths for synthetic output (and reference data if incremental).
   - Adjust checkbox settings as required (GQ, Incremental).

2. **Click "Run POPSIM"**:
   - Initiates the synthetic population generation.
   - Monitors for the creation of output files, indicating successful completion.

3. **Finalize or Cancel**:
   - Click **OK** to save current settings and close.
   - Click **Cancel** to discard changes and close without saving.
