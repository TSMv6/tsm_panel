# TSM Main Panel User Guide

## Introduction
The Main Panel serves as the central hub for managing and operating various components of the Turnpike State Model (TSM). It offers structured navigation through General & Project Settings, Editors, the "Black Box," and the "Analyst," streamlining workflows and enhancing accessibility for users.

---

## Panel Overview

### 1. General & Project Settings
- **General Configuration:** Access settings related to general model dependencies and paths.
- **Load Settings:** Load previously saved model configurations.
- **Scenario Specs:** Define specific scenario parameters.
- **Save Settings:** Save current configurations for future use.

---

### 2. Editors
- **SE Data Editor:** Edit socio-economic data crucial for model accuracy.
- **Multi-Spatial Resolution (MSR):** Manage multi-level spatial data resolutions.
- **Database Review:** Review and verify database integrity and consistency.
- **GeoMaster Editor:** Edit and manage GeoMaster data layers.

---

### 3. The "Black Box"
This section houses essential model processes divided into specialized groups:

#### Network Modeler
- **Network Manager:** Manages overall network structure and attributes.
- **Settings:** Configure specific network modeling options.
- **Link Consolidator (Many-to-One):** Reduce network complexity by consolidating links.
- **Subarea Networks:** Extract and manage subarea networks.

#### Demand Model
- **PopSyn:** Generate synthetic population data.
- **Skimmy:** Develop network skim matrices.
- **SDT Resident:** Model short-distance resident travel.
- **SDT Visitor:** Model short-distance visitor travel.
- **LDT Resident:** Analyze long-distance resident travel.
- **LDT Visitor:** Analyze long-distance visitor travel.
- **Truck Trip Table:** Generate truck-specific travel tables.
- **List -> Table:** Convert trip lists into structured tables.

#### Route Choice Models
- **TSM Assignment:** Execute traffic assignment within TSM.
- **ELToD Assignment:** Run advanced assignment modeling using **ELToD** (Express Lanes Time of Day).

---

### 4. The "Analyst"
- **Summarization:** Aggregate and summarize model results.
- **Visualizations:** Create visual representations of modeling outcomes for analysis.

---

## Widget Interaction
- Each widget provides intuitive buttons and dropdowns for quick access.
- Collapsible group boxes help organize and simplify panel navigation.
- Checkboxes and action buttons facilitate easy toggling of features and execution of model tasks.

---

## Importance and Efficiency
The Main Panel significantly enhances the usability and efficiency of TSM:
- Centralizes management of all critical TSM functions.
- Streamlines workflow, enabling quicker execution and better organization.
- Reduces complexity and user effort through a structured and interactive interface.

---

## Additional Notes
- Regularly save and load settings to streamline repeated model runs.
- Ensure accuracy and consistency by routinely verifying configurations within the General & Project Settings.
- Leverage the Analyst section for comprehensive analysis and effective communication of modeling results.
