# Turnpike State Model (TSM) - User Interface

## Introduction

This comprehensive user guide compiles detailed descriptions and functionalities of the Turnpike State Model (TSM) tools and widgets, organized according to the TSM Main Panel structure. It facilitates streamlined workflow and effective utilization of the TSM.



---

## 1. General & Project Settings

### General Configuration

Manage key dependencies, including paths to Java, RScript, and TSM directories, as well as processor allocation.



### Scenario Specs

Define scenario-specific details, geographic coverage, input layers, and model execution steps.



---

## 2. Editors

### SE Data Editor

Edit socio-economic data vital for accurate modeling.

### Multi-Spatial Resolution (MSR)

Manage and analyze spatial data at multiple resolutions.

### Database Review

Review databases for accuracy and consistency.

### GeoMaster Editor

Edit and manage GeoMaster datasets efficiently.

---

## 3. The "Black Box"

### Network Modeler

#### Network Editor Tool

- Quickly select and edit network layers.
- Automate link and node updates.
- Integrate seamlessly with QGIS for improved workflow efficiency.



#### Link Consolidator (Many-to-One)

- Simplify networks by merging multiple links.
- Reduce computational load without sacrificing geometric accuracy.



#### Subarea Networks

- Efficiently extract subarea networks and manage node consistency across scenarios.



### Demand Model

#### PopSyn

- Generate synthetic population data using specified configurations.



#### Skimmy

- Create skim matrices based on network attributes.



#### Short Distance Travel (SDT)

- **SDT Resident:** Model resident short-distance travel.
- **SDT Visitor:** Model visitor short-distance travel within and outside Florida.



#### Long Distance Travel (LDT)

- **LDT Resident:** Analyze Florida resident long-distance travel patterns.
- **LDT Visitor:** Analyze long-distance travel for out-of-state (non-Florida) US visitors.



#### Truck Trip Table

- Generate detailed truck trip tables.

#### List -> Table

- Convert trip lists into structured tables for analysis.

### Route Choice Models

#### TSM Assignment

- Execute detailed traffic assignment tasks.



#### ELToD Assignment

- Perform advanced assignment analyses with **ELToD** (Express Lanes Time of Day) — a semi-static, quasi-DTA assignment (interval-by-interval BPR with planning-level ramp and signal delay).
