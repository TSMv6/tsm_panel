# SDT Visitor GUI Widget User Guide

## Introduction
The SDT Visitor widget facilitates modeling Short Distance Travel (SDT) specifically for visitors within the Turnpike State Model (TSM). It leverages regional land-use data and travel skim matrices to predict visitor travel patterns and demands.

---

## GUI Overview

### Data Input Configuration

#### 1. **Land-use Layer**
- **Description:** Chooses the polygon land-use layer, initially at the regional planning model resolution, which is internally aggregated to the TSM zoning system.
- **Interaction:** Select an appropriate polygon land-use layer from the dropdown menu.

#### 2. **Skim File**
- **Description:** Provides the necessary skim matrix containing distance tables used for visitor travel modeling.
- **Interaction:** Click **Browse** to select the required skim file.

---

### Output Directory

- **Description:** Specifies the directory where model outputs will be saved.
- **Interaction:** Enter the directory manually or click **Browse** to choose the location.

---

## Execution and Saving

### Run SDT Visitor
- Click **Run SDT Vis** to execute the visitor model using the configured settings.

### Save or Cancel Configuration
- Click **OK** to save the current settings for future runs.
- Click **Cancel** to discard unsaved changes and close the widget.

### Additional Notes
- Ensure the selected land-use layer and skim file accurately represent visitor characteristics and travel patterns.
- Confirm the output directory has adequate storage capacity and is accessible.
- Regularly review VisitFL and FDOT data to maintain updated visitor modeling assumptions and inputs.
